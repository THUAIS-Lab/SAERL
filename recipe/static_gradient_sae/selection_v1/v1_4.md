# Gradient-SAE Functional Redundancy Selection（v1.4）

## 1. 阈值表示

只读取 sample-level Dense representation 的 response mean：

$$
m_i=x_i^{\mathrm{dense}}[2F:3F]\in\mathbb{R}^{F}.
$$

给定 feature threshold $\delta\ge0$，逐 sample 定义

$$
z_{if}=m_{if}\mathbf 1[|m_{if}|>\delta].
$$

即绝对值严格大于 $\delta$ 的 feature 保留原始符号和值，其余（包括恰好等于阈值）置 0。
本版本不使用 prompt、`response_signed_peak` 或 Token-TopK representation。

## 2. Signal Strength 与 Pattern

所有后续计算都使用阈值化后的 $z_i$：

$$
M_i=\lVert z_i\rVert_2,
\qquad
u_i=\frac{z_i}{M_i}.
$$

`zero_signal_dense=true` 或 $M_i\le\epsilon$ 的 sample 进入 silent set；其余 sample 按
$M_i$ 降序、`sample_id` 升序处理。

## 3. Signed Cosine 去冗余

候选 sample $i$ 与已选 sample $j$ 的相似度为

$$
s_{ij}=u_i^\top u_j=\cos(z_i,z_j).
$$

令 $r_i=\max_{j\in S}s_{ij}$：

- 若 $r_i\ge\tau$，则 $i$ 冗余；
- 否则保留 $i$ 并加入 $S$。

必须保留 cosine 的符号，符号相反的 pattern 不视为冗余。完整流程为

$$
\text{Dense response mean}
\rightarrow
\text{sample-level absolute thresholding}
\rightarrow
\text{L2 normalization}
\rightarrow
\text{signed-cosine pruning}.
$$

阈值只控制单坐标是否保留，不直接限制单样本非零数或全数据 feature union。阈值过低时稀疏
矩阵仍可能很大，应根据 response mean 的绝对值分布选择 $\delta$。

## 4. 运行

```bash
python recipe/static_gradient_sae/selection_v1/select_v1_4.py \
  --run-dir /path/to/extraction-run \
  --feature-threshold 0.001 \
  --cosine-threshold 0.98
```

结果默认写入 `RUN_DIR/selection_v1_4/`。
